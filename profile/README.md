# 搬瓦工 IP 被封了怎么办

SSH 连不上，Ping 全丢包，网站打不开。可 KiwiVM 后台显示机器运行正常。

遇到这种情况，八成是 IP 在国内被封了。搬瓦工没挂，你家网络也没坏。

这种封锁发生在网络层。机器还在跑，从美国访问一切正常，只有来自国内的请求被拦下来。

## 先确认是不是真被封

别急着换 IP，先排除几种更常见的小问题。

登录 KiwiVM，找到对应的机器，用官方的检测工具测一下主 IP，结果最直接。

再打开 ping.pe，输入你的 IP。它会从全球各地同时 ping 一次。国外节点通、国内节点全红，基本就能确定。

如果 IP 能 ping 通，只是 SSH 连不上，那可能是端口的问题，不是整个 IP 被封。用 port.ping.pe 测一下端口更清楚。

## 确认被封之后

几个办法，按成本和效果排。

**等。** 重装系统或者关机放着，一两个月后有机会自己解开。不花钱，就是等得久。

**迁机房。** 后台有 Migrate to another DC，换机房会分配新 IP。不过 IP 被封之后这个功能经常被限制，能不能用要看套餐。

**付费换 IP。** 这是目前最稳的官方办法。在后台提交换 IP 申请，付款后很快就能换好，费用页面上能看到。新 IP 到手，记得同步改域名解析和 SSH 配置。

**套 Cloudflare。** 如果是做网站，把域名挂到 Cloudflare 后面，访客访问的是 CF 的节点，源站 IP 被藏起来。这不算解封，是绕过去继续用。

**上 IPv6。** 部分机房支持 IPv6，IPv4 被封的时候 IPv6 可能还通。

**买新的。** 最彻底，也最贵。适合实在不想折腾，或者手里是绝版套餐的情况。

## 怎么少被封几次

用正常用途。扫描端口、跑爬虫、大量外连，这些最容易触发封锁。
