# 搬瓦工常见问题

几个问得最多的问题，直接说结论。

## IP 被封了怎么办

先确认是不是真被封。Ping 不通不一定是封，有时候网站和 SSH 都能用，只是它不回应 Ping。

进 KiwiVM 看看机器是不是在跑，SSH 端口有没有填错。都没问题，再换手机热点试一次。

确实被封了，可以付费换 IP。费用和到账时间问客服，别照旧文章里的数字付款。

想靠迁机房解决的话，得等这个 IP 连续七天不在黑名单里。不是从你发现那天算起。

## 能退款吗

有退款期，具体天数看服务条款。过了期限就不行，续费也不算新订单。

买之前想清楚用途，比事后申请退款省事。

## 速度怎么样

没法一概而论。同一个机房，电信、联通、移动的体验不一样，你在哪个城市也不一样。

自己 ping 一下测试 IP 最准。白天测一次，晚上再测一次。

## 能建站吗

能。这是台自己管的服务器，装环境、配域名、做备份都要自己来。

不想折腾这些，虚拟主机更省事。想要自由度和性能，VPS 才对。

## 支持哪些付款方式

支付宝、PayPal、信用卡。支付宝按当天汇率扣人民币，最方便。

## 到期不续费会怎样

机器会被停掉，数据保留一段时间后删除。不打算续了，提前把数据备份出来。
