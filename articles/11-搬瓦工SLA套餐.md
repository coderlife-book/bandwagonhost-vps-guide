# 搬瓦工 SLA 套餐值得买吗？DC5 价格、免费换 IP 和保障范围

搬瓦工 SLA 套餐适合需要明确可用性条款的人。入门款 SLA 20G 在洛杉矶 USCA_5，季付 65.89 美元、年付 239.99 美元，还提供每两周免费换一次 IP 的服务。

如果只是学 Linux，我会先看普通 KVM。网站准备长期跑业务，再比较 SLA 多出来的条款是否用得上。

## SLA 20G 买到什么

入门配置是约 1 GB 内存、20 GB NVMe 硬盘、每月 1 TB 流量和 2.5 Gbps 端口。当前只对应洛杉矶 USCA_5，也就是常说的 DC5。

官网给这个机房列出的中国方向线路包括电信 CN2 GIA、移动 CMIN2 和联通 Premium。SLA 是服务条款，线路是网络选择，两件事要分开看。

## 99.99% SLA 是什么

它是按月计算、有适用范围的可用性承诺。符合条件的故障可以申请增加服务时间，补偿落在出故障的那台 VPS 上。

这不是现金赔偿，也不是对所有连不上情况都补偿。自己的系统配置、第三方网络和 IP 封锁等情况有排除条款。要判断具体问题是否适用，直接看[SLA 条款](https://bandwagonhost.com/sla)最清楚。

## 免费换 IP 怎么理解

套餐提供的是每两周免费换一次 IP 的服务，不是系统每两周自动换一次，也不是每次连接失败都应该换 IP。

我会先检查服务和网络。换 IP 后，域名解析、SSH 连接地址和其他用到旧 IP 的地方，也要一起调整。

## 和 CN2 GIA 20G 怎么选

常规 CN2 GIA 20G 年付 169.99 美元，能选多个机房。SLA 20G 年付 239.99 美元，两者相差 70 美元。

需要在不同机房之间调整位置，先看常规 CN2 GIA。明确需要 SLA 条款，且接受 USCA_5 这个位置，再考虑 SLA 20G。

两款入门配置接近，多付的钱有没有意义，要看服务要求。还没定好这一点，可以先看[三档套餐的区别](02-搬瓦工套餐评估.md)。

## 准备跑业务，就把条款一起看

我会把 SLA 当成选购条件之一，同时保留自己的备份和监控。确认位置、配置和服务范围都符合用途，再下单。
